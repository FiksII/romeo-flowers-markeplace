# Развёртывание маркетплейса на сервере

**Цель:** заменить старый сайт на `flowers.aestory.space` текущей проверенной версией маркетплейса по прямому запросу пользователя.

**Среда:** сервер пользователя, Caddy, systemd, Gunicorn, PostgreSQL. Новый код и база отделены от старого магазина. Публикуется демонстрационная версия без реальных платежей, с HTTPS и `DEBUG=False`.

## Шаги и проверка

- [x] Проверить службы, домен, исходную папку, PostgreSQL и инструкции старого проекта без вывода секретов.
- [x] Создать резервную копию старой базы, исходников, media и конфигурации прокси/службы; проверить наличие копий.
- [x] Зафиксировать Gunicorn для Linux; добавить режим HTTPS-превью, наследующий защищённые production-настройки, и проверить его.
- [x] Передать архив исходников без секретов, локальной БД и runtime-каталогов; сравнить SHA256.
- [x] Подготовить отдельного системного пользователя, PostgreSQL-роль/базу, секрет окружения и постоянный каталог media. Установить зависимости по lock-файлу.
- [x] Применить миграции, создать шестинедельную демо-историю; заменить начальные пароли новых аккаунтов случайными до публикации и сохранить доступы в закрытом файле.
- [x] Проверить Django deploy-check, статику, новый Gunicorn на loopback, страницы и доступы ролей.
- [x] Проверить новую конфигурацию Caddy, переключить маршрут, остановить и отключить автозапуск старой службы. Сохранить способ возврата к ней.
- [x] Проверить HTTPS с доверенным сертификатом, статические файлы, media, службы и журналы; проверить входы и дашборды серверными запросами, зафиксировать результат и инструкцию отката.

Результат: [инструкция развёртывания и отката](../../deployment.md). На сервере прошли 82 теста; рабочая роль PostgreSQL не имеет повышенных прав. Браузерная автоматизация завершилась тайм-аутом подключения; проверка интерфейса через неё не заявляется.

## Ограничения

- Не менять старую базу и исходники, существующие аккаунты, SSH-пароль, посторонние службы и firewall.
- Не публиковать локальный `demo_settings` с DEBUG/SQLite или начальные пароли генератора.
- Не переносить данные старого одиночного магазина в несовместимую новую модель автоматически.
- Не подключать платежи или рабочую DaData без их настройки. Демо явно обозначено на сайте.
- При неуспешной проверке после переключения вернуть сохранённую конфигурацию Caddy и старую службу.
