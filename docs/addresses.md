# Адреса и карты

Поиск адресов магазина и доставки использует DaData при заполненном `DADATA_TOKEN` в `.env`. Ключ остаётся на сервере; браузер обращается к `/addresses/` и `/addresses/resolve/`.

Подсказки ограничены Москвой и Московской областью (КЛАДР 77/50). При выборе дома сервер уточняет его через `count=1` и `unrestricted_value`. Принимаются только координаты выбранного дома (`qc_geo=0`); координаты улицы, города или ближайшего дома отклоняются. Перед сохранением координаты округляются до шести знаков после запятой, как в модели магазина. Выбранный адрес получает подписанный токен; подпись подсказки сама по себе не позволяет оформить заказ или изменить адрес магазина.

`MARKET_DEMO=True` сохраняет демонстрационные товары и заказы. Адреса управляются отдельно: по умолчанию ключ DaData включает реальный поиск, `ADDRESS_DEMO=True` возвращает три демонстрационных адреса. Для дева с реальным поиском задайте `ADDRESS_DEMO=False`.

Список и уточнение адреса кешируются на сервере на пять минут. Запросы при вводе задерживаются на 280 мс; координаты уточняются только для выбранного дома. Оба маршрута используют общий лимит 120 обращений в минуту на IP. При недоступности подсказок покупатель может продолжить просмотр по городу.

Без ключа DaData остаётся существующий поиск OpenStreetMap; `OSM_ADDRESS_SEARCH=False` отключает его. В тестовых настройках внешние провайдеры отключены независимо от локального `.env`.

Для карты магазина и редактора зоны задайте `YANDEX_TILES_API_KEY` от **Tiles API**. Без ключа остаётся OpenStreetMap. Карта использует сферическую проекцию `web_mercator`, совместимую с Leaflet. Официальный логотип Яндекса и ссылка на Яндекс Карты показываются в углу карты. Ключ тайлов виден в браузере: в кабинете Яндекса ограничьте HTTP Referer доменами сайта. Новый ключ может активироваться до 15 минут.

Бесплатная DaData даёт до 10 000 запросов в день суммарно по видам подсказок; ссылка на DaData показана под адресным полем. Tiles API бесплатно до 30 запросов в секунду. В этой связке поиск и сохранение адресов не используют геокодер Яндекса.

Документация и актуальные условия:

- [DaData: подсказки адресов](https://dadata.ru/api/suggest/address/)
- [DaData: тарифы](https://dadata.ru/pricing/)
- [Яндекс: Tiles API](https://yandex.ru/maps-api/docs/tiles-api/index.html)

## Подсказки по началу названия

Во всех адресных формах используется общий поиск с двух введённых символов
и паузой 280 мс. DaData возвращает города, улицы и дома: промежуточные
результаты больше не отбрасываются из-за отсутствия номера дома. Например,
«Оди» предлагает Одинцово, а «Одинцово, Лени» — подходящие улицы и территории.
Частичное совпадение поддерживается сервисом для последнего слова запроса.

Выбор города или улицы подставляет текст с запятой и оставляет поле в фокусе
для следующей части адреса. Промежуточный результат не получает адресного токена
и не перемещает карту. Только выбранный дом проходит прежнюю проверку точных
координат и получает подписанный адрес для заказа или сохранения магазина.
Новые зависимости не требуются; используется действующий API DaData.
