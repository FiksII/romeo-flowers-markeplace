# Flower Shop design assets

Extracted from the user-supplied `Flower Shop.pdf` (51 pages, September 2026) and
converted to WebP with transparency preserved. Product photography still comes
from Django Oscar product images; do not replace real product photos with
mockup photos.

| File | Used for |
| --- | --- |
| `logo.webp`, `emblem.webp` | header, footer, loyalty card |
| `hero.webp`, `peonies.webp`, `loyalty-peonies.webp` | home hero slides, loyalty banner and dialog |
| `category-*.webp` | category circles on the home page |
| `rose.webp` … `carnation.webp` | flower-type rail on the home page |
| `florist.webp` | sign-in / registration photo, occasion dialog |
| `bonus-*.webp` | «К этому букету вы обязательно получите» on the product page |
| `postcard-preview.webp`, `postcard-thumb.webp` | postcard picker preview, order detail |
| `login-prompt.webp`, `petals.webp`, `petal-1.webp` … `petal-5.webp` | checkout gateway; single petals (cut from `petals.webp`) on the order-placed, gift and status cards |
| `loyalty-card.webp`, `stamp-rose*.webp`, `gift-10.webp`, `gift-11*.webp`, `gift-box.webp` | account overview and loyalty pages |
| `status-*.webp`, `promo-50.webp` | demo-only account widgets (`SHOP_DEMO_SERVICES=True`) |
| `pay-*.webp` | demo payment method logos |
| `help-bouquet.webp`, `review-anna.webp` | account sidebar, home reviews |

Small illustrations are capped at 240 px, the logo at 550 px, editorial images at 1400 px.
